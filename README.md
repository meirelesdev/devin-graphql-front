# Devin Graphql Front

> Frontend React que consome uma API GraphQL via Apollo Client, com formularios validados por Formik/Yup e estilizacao com Styled Components.

## Stack

- React
- Apollo Client
- GraphQL
- Styled Components
- Formik

## Prerequisitos

- Node.js v14+

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/devin-graphql-front.git
cd devin-graphql-front

# Instale as dependencias
npm install

# Inicie a aplicacao
npm start
```
